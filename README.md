# Проект базы данных «Автосервис»

Две готовые базы SQLite, отчёт и SQL-скрипты. Откройте autoservice_v1.sqlite или autoservice_v2.sqlite в DB Browser for SQLite. Скрипты create_v1.sql и create_v2.sql применяются к пустым базам. Запросы в queries.sql; последние два запроса относятся к версии 2. Включите внешние ключи командой `PRAGMA foreign_keys=ON;` в каждом соединении.
